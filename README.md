# Data Science Task

This repository contains the work I completed during my 4-week Data Science Internship (June 25, 2025 – July 25, 2025).

During this internship, I gained hands-on experience in data analysis, machine learning, and solving real-world problems using Python. I worked on multiple projects that helped me understand the complete data science workflow, from data preprocessing to model building and evaluation.

Key Learnings:
1. Data preprocessing and exploratory data analysis (EDA)
2. Feature engineering and model evaluation
3. Machine learning using Python
4. Working with libraries like Pandas, NumPy, and visualization tools
   
Projects Included:
1. Titanic Survival Prediction – Classification model to predict survival
2. Iris Flower Classification – Supervised learning for classification
3. Sales Prediction – Forecasting sales using historical data

This internship helped me improve my analytical skills and build a strong foundation in practical machine learning.
